About Program

Firearm Registry System
VERSION 1.0.5 — IT 120 ACTIVITY 4 & 5

A web-based Firearm Registry and Licensing Management System built for IT 120. Integrates Activity 5 user management with three primary transactions (Sales, Firearm Borrowing, Inventory Count) and Excel report generation with data grids, company header, signature placeholders, and chart sheets.

DB Architecture
Public Class MySQLConnection (Singleton Pattern)
System Features
  • ✓User Authentication — Secure login with username/password validation and account status check.
  • ✓Password Recovery — 3-step token-based password reset (email → code → new password).
  • ✓User Management — Add, update profile, activate/deactivate accounts, delete users.
  • ✓Account Search & List — Filter by role/status, sortable columns, pagination.
  • ✓Inventory Management — Add/edit/delete firearm records, export to CSV.
  • ✓Sales Transaction — Record firearm sales and update inventory status.
  • ✓Firearm Borrowing — Issue and return borrowed firearms (book-borrowing pattern).
  • ✓Inventory Count — Physical audit with variance tracking and batch count.
  • ✓Report Generation — Data grid reports with MS Excel export (header, logo, signature, Sheet 2 chart).
  • ✓Public MySQL Class — Singleton DB connection class with select, insert, update, delete methods.
  • ✓Session Management — Auth guards on all protected pages with session storage.
